# YourTube

Мини-клон YouTube на FastAPI, PostgreSQL и JavaScript. FFmpeg преобразует загруженное видео в MP4 (H.264/AAC) и создаёт обложку. Плеер поддерживает перемотку через HTTP Range.

## Запуск на Ubuntu

Из каталога с исходниками выполните одну команду:

```bash
bash deploy.sh
```

Нужны Ubuntu с systemd, доступ в интернет и права sudo. Скрипт при необходимости установит Docker Engine, Buildx и Compose из официального APT-репозитория Docker, затем соберёт приложение и дождётся готовности обоих контейнеров. Повторный запуск обновляет приложение и использует существующие тома и пароль из `.env`.

- Интерфейс — http://localhost:8000/
- Swagger — http://localhost:8000/docs
- `sudo docker compose ps` — состояние контейнеров.
- `sudo docker compose logs -f app` — журнал приложения.
- `sudo docker compose down` — остановка с сохранением данных.

В `.env` можно поменять `YOURTUBE_PORT` и `YOURTUBE_BIND` (по умолчанию `0.0.0.0`). Для HTTPS за обратным прокси укажите внешний адрес в `PUBLIC_ORIGIN`, например `https://video.example.org`, и установите `COOKIE_SECURE=1`. Затем повторно запустите установщик.

PostgreSQL доступен внутри сети Compose. Каталоги `postgres_data` и `video_data` хранят базу и медиа. Сохраняйте оба каталога и `.env` при переносе экземпляра. Пароль базы создаётся при первом запуске и соответствует паролю в уже инициализированной базе.

Одновременно принимаются две загрузки на весь экземпляр и одна на аккаунт. Между принятыми попытками одного аккаунта действует пауза в 60 секунд, включая попытки с повреждёнными файлами. Передача файла ограничена пятью минутами. При занятом сервере API отвечает `503`, при ограничении аккаунта — `429`. Оба ответа содержат `Retry-After`.

## Первый сценарий

1. Зарегистрируйтесь и загрузите видео. После передачи файла FFmpeg готовит MP4 и обложку. По умолчанию размер исходника ограничен 512 МиБ. Лимит в байтах можно задать через `UPLOAD_MAX_BYTES` в `.env`.
2. Откройте видео в ленте или найдите его по части названия. На странице просмотра доступны лайки, комментарии, подписка и жалоба.
3. В разделе «Мои видео» откройте настройки ролика. Для приватного видео введите имя другого зарегистрированного пользователя, чтобы выдать доступ. Получатель увидит ролик в разделе «Доступные мне». Отзыв доступа закрывает последующие запросы на просмотр и обложку.
4. Создайте плейлист во вкладке своего канала. Добавляйте ролики со страницы просмотра.
5. Для первого администратора зарегистрируйте аккаунт, например `owner_admin`, и выполните команду на хосте. Подставьте имя своего аккаунта:

```bash
sudo docker compose exec db psql -U yourtube -d yourtube \
  -c "UPDATE accounts SET role='admin' WHERE handle='owner_admin';"
```

Администратор назначает модераторов в разделе «Модерация». Модератор и администратор рассматривают жалобы, скрывают и восстанавливают ролики. Роль сама по себе не даёт доступа к просмотру приватных роликов.

Установка рассчитана на один сервер с локальными томами.

## Тестовые данные

После запуска приложения выполните:

```bash
bash deploy.sh
sudo docker compose exec -T app python -m app.seed_demo
```

Миграция добавит два канала, четыре воспроизводимых ролика, плейлист, подписки, лайки, комментарии и открытую жалобу. Три видео появятся в ленте. Четвёртое доступно владельцу `demo_studio` и пользователю `demo_viewer`. Жалобу можно обработать под `demo_moderator`. Под `demo_admin` также можно назначать модераторов. Повторный запуск на базе с прежними демо-данными добавит администратора.

Пароли тестовых аккаунтов генерируются при первом запуске и выводятся один раз. Повторный запуск пропускает уже применённую миграцию. Миграция запускается вручную на выбранном экземпляре.

Для отката тестовых данных выполните:

```bash
sudo docker compose exec -T app python -m app.seed_demo down
```

Откат удаляет демо-аккаунты, их активность, тестовые ролики и связанные с ними записи, а также файлы тестовых роликов в `video_data`. Если у демо-аккаунтов есть собственные загрузки, откат отменяется целиком. Повторный `down` безопасен. Команда `up` (или запуск модуля без аргумента) создаёт демо-данные заново и выдаёт новые пароли.
